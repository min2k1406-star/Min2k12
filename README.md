# 🎬 영상 대본 & 리서치 자료 자동 수집기 (Video Script & Doc Collector)

영상 제작 및 다큐멘터리 기획, 리서치, 영상 콘티 작성 시 필요한 **유튜브 영상 자막/대본**과 **웹 기사·블로그 본문**을 클릭 한 번으로 마크다운(`.md`) 파일로 자동 정리해 주는 파이썬 도구입니다.

---

## ✨ 핵심 기능

1. **유튜브 자막 & 스크립트 완벽 추출**
   - 한국어 자막(수동/자동생성) 및 영어 자막 자동 지원
   - **줄글 요약본**: 대본 전체를 술술 읽을 수 있는 문단형 텍스트
   - **타임코드별 스크립트**: `[01:23] 대사...` 영상 편집 및 싱크 맞춤용 타임스탬프 지원
2. **웹 기사 & 블로그 본문 클린 스크랩**
   - 뉴스 기사, 브런치, 티스토리, 인터뷰 기사 등 링크만 넣으면 광고, 배너, 메뉴를 싹 지우고 순수 본문만 추출
3. **자동 마크다운 문서화**
   - `output/` 폴더에 제목과 날짜, 출처 URL이 포함된 깔끔한 `.md` 파일로 즉시 저장

---

## 🚀 사용법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 실행 방법

#### ① 단일 링크 즉시 추출
```bash
python main.py "https://www.youtube.com/watch?v=영상ID"
python main.py "https://n.news.naver.com/article/기사링크"
```

#### ② 여러 링크 파일로 한 번에 추출 (일괄 처리)
`urls.txt` 파일에 한 줄에 하나씩 링크를 적어두고:
```bash
python main.py urls.txt
```

#### ③ 대화형 모드 (링크 하나씩 붙여넣기)
```bash
python main.py
```
실행 후 프롬프트에 URL을 엔터로 계속 붙여넣으시면 됩니다. (종료: `q`)
